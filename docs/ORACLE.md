# Бот 24/7 бесплатно на Oracle Cloud (Always Free)

Oracle бесплатно даёт небольшой сервер на Linux. Боту этого хватает с большим
запасом. Вся настройка занимает примерно 20–30 минут.

Открывать порты, покупать домен и настраивать вебхук не нужно: бот сам
обращается к Telegram и к сайту с расписанием.

---

## Шаг 1. Регистрация

1. Откройте https://signup.cloud.oracle.com и заполните форму.
2. **Home Region** — выберите ближайший регион, например *Germany Central (Frankfurt)*.
   ⚠️ Регион нельзя поменять потом, а бесплатные ресурсы есть только в нём.
3. Привяжите банковскую карту. Она нужна только для проверки личности:
   Oracle может временно заблокировать около $1 и затем вернуть.
   Пока аккаунт бесплатный (*Free Tier*), списаний не будет.
4. Дождитесь письма о том, что аккаунт готов. Обычно это несколько минут,
   иногда до часа.

> Если Oracle отказал в регистрации, попробуйте другую карту или другой браузер
> без VPN. Если не помогло, переходите на запасной вариант в конце инструкции.

## Шаг 2. Создание сервера

1. Войдите на https://cloud.oracle.com и откройте меню ☰ → **Compute** → **Instances**
   → **Create instance**.
2. **Name**: `helpmyschedule`.
3. **Image and shape** → **Edit**:
   - **Image** → *Change image* → **Ubuntu** → *Canonical Ubuntu 24.04* (обычная, не Minimal).
   - **Shape** → *Change shape*. Подойдёт любой вариант с пометкой **Always Free-eligible**:
     - **Ampere** → `VM.Standard.A1.Flex`: 1 OCPU и 6 GB памяти — более мощный вариант;
     - или **AMD** → `VM.Standard.E2.1.Micro` (1 GB памяти) — этого тоже хватит.
       Выбирайте его, если Ampere выдаёт ошибку *Out of capacity*.
4. **Networking**: оставьте значения по умолчанию. Обязательно должна стоять галочка
   **Assign a public IPv4 address**.
5. **Add SSH keys** → **Generate a key pair for me** → **Save private key**.
   Сохраните файл `ssh-key-….key`: без него на сервер не зайти.
6. Нажмите **Create**. Через 1–2 минуты статус станет **Running**.
   Скопируйте **Public IP address**, например `130.61.12.34`.

## Шаг 3. Подключение к серверу

**Windows** (PowerShell):
```powershell
ssh -i "$HOME\Downloads\ssh-key-2026-11-09.key" ubuntu@130.61.12.34
```

**macOS / Linux** (Терминал):
```bash
chmod 600 ~/Downloads/ssh-key-2026-11-09.key
ssh -i ~/Downloads/ssh-key-2026-11-09.key ubuntu@130.61.12.34
```

Подставьте своё имя файла и свой IP. На вопрос *Are you sure you want to continue connecting*
ответьте `yes`.

> Если Windows пишет *UNPROTECTED PRIVATE KEY FILE*: правый клик по файлу ключа →
> Свойства → Безопасность → Дополнительно → Отключить наследование → удалите всех,
> кроме своего пользователя.

## Шаг 4. Установка бота

Выполните на сервере по очереди:

```bash
sudo apt-get update && sudo apt-get install -y git
git clone https://github.com/F1rdavsss1/helpmyschedule.git
cd helpmyschedule
git checkout claude/telegram-schedule-bot-tmxqej   # не нужно, если ветка уже влита в main
bash deploy/setup.sh
```

Скрипт попросит токен бота. Вставьте его (в PowerShell — правой кнопкой мыши)
и нажмите Enter. Символы при вводе не отображаются, так и должно быть.

В конце должно появиться:

```
✅ Бот запущен и будет работать постоянно (в том числе после перезагрузки сервера).
```

Откройте бота в Telegram и отправьте `/start`. Теперь SSH-окно можно закрыть:
бот продолжит работать.

> ⚠️ Если бот запущен ещё и на вашем компьютере, остановите его там. Когда работают
> две копии с одним токеном, Telegram выдаёт ошибку *Conflict: terminated by other getUpdates request*.

## Полезные команды

```bash
journalctl -u helpmyschedule -f          # логи в реальном времени (выход — Ctrl+C)
sudo systemctl status helpmyschedule     # работает ли бот
sudo systemctl restart helpmyschedule    # перезапуск (например, после правки .env)
nano ~/helpmyschedule/.env               # изменить настройки
bash ~/helpmyschedule/deploy/update.sh   # обновить бота до последней версии из GitHub
```

В логах каждые 20 минут появляется строка вроде `Изменений нет (…)`. Это значит,
что проверка расписания работает.

## Чтобы Oracle не выключил сервер

Oracle может забрать бесплатный сервер, если тот почти не нагружен в течение 7 дней.
Наш бот как раз почти не нагружает сервер. Варианты:

1. **Ничего не делать.** На практике сервера часто живут месяцами. Если Oracle
   остановит сервер, придёт письмо: создайте сервер заново и повторите шаги 2–4.
   Это 15 минут.
2. **Перейти на Pay As You Go** (☰ → **Billing & Cost Management** → **Upgrade and Manage Payment**).
   Простаивающие серверы на таком аккаунте Oracle не отключает, а ресурсы с пометкой
   *Always Free* по-прежнему бесплатны. Риск один: если вы сами создадите что-то
   платное, за это спишут деньги. Для страховки сразу настройте **Budgets**
   (☰ → Billing → Budgets) с лимитом $1 и уведомлением на почту.

Специально нагружать процессор, чтобы обмануть проверку, не советую: это против
правил Oracle.

## Частые проблемы

| Проблема | Что делать |
|---|---|
| *Out of capacity* при создании сервера | Выберите shape `VM.Standard.E2.1.Micro` или повторите попытку позже |
| `Connection timed out` при SSH | Проверьте IP; сервер должен быть в статусе Running |
| `Permission denied (publickey)` | Проверьте путь к `.key` и логин `ubuntu@` |
| Скрипт пишет «Telegram не принял токен» | Скопируйте токен из @BotFather заново: `nano ~/helpmyschedule/.env`, затем снова `bash deploy/setup.sh` |
| «Не удалось получить расписание с сайта» | Проверьте вручную: `cd ~/helpmyschedule && .venv/bin/python parser.py`. Если сайт не отвечает серверам за границей, выберите другой регион или запасной вариант |
| Бот не отвечает | Посмотрите `journalctl -u helpmyschedule -n 50` |

## Запасной вариант без Oracle

Тот же `deploy/setup.sh` работает на любом компьютере с Ubuntu или Debian: на старом
ноутбуке, Raspberry Pi или другом VPS. Главное, чтобы устройство было постоянно
включено и в сети.
